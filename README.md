# 시드니픽 · SYDNEY PICK

한국인 자유여행자를 위한 시드니 일정·지역·준비 가이드입니다.

- 대표 도메인: https://sydneypick.com
- 핵심 일정: 5박 6일 FIRST PICK
- 디자인: 화이트, 하버블루, 코럴 포인트
- 정보 원칙: 임시 상호·가격·주소·후기·운영정보를 실제 정보처럼 사용하지 않음
- 사실 확인: 예약·방문 전 Destination NSW, Transport for NSW, 호주 기상청 등 공식 채널 재확인

## 콘텐츠 구조

히어로 → 빠른 탐색 → 일정별 픽 → 지역별 픽 → 여행 준비 → 맛집·카페 → 쇼핑픽 → SDF → 픽 매거진 → 무료 가이드

## 이미지

여행 사진은 Unsplash 라이선스 이미지를 사용하며, 사이트의 목업 이미지를 페이지에 삽입하지 않습니다.

## 배포 구조

- 프레임워크: Other / Vanilla Static Site
- 빌드 명령: `npm run build`
- 출력 폴더: `dist`
- `src/site.js`: 브라우저 전용 인터랙션
- `scripts/preview.mjs`: 로컬 production preview 전용 서버
- 환경변수: 필요 없음
