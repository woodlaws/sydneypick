# 시드니픽 · SYDNEY PICK

한국인 자유여행자를 위한 시드니 일정·지역·여행 준비 가이드입니다.

## 배포 정보

- 운영 도메인 기준: https://sydneypick.com
- Vercel 빌드 명령: `npm run build`
- 출력 폴더: `dist`
- 환경변수: 필요 없음
- 프레임워크: Other / Static Site

## 구성

- `index.html`: 메인 홈페이지와 SEO 메타데이터
- `styles.css`: 데스크톱·모바일 반응형 디자인
- `app.js`: 일정 선택, 검색, 체크리스트 인터랙션
- `public/og.png`: 소셜 공유 이미지
- `robots.txt`, `sitemap.xml`: 검색엔진 크롤링 설정
- `vercel.json`: Vercel 빌드·출력 설정

자세한 절차는 [GITHUB-VERCEL-DEPLOY.md](./GITHUB-VERCEL-DEPLOY.md)를 확인하세요.
